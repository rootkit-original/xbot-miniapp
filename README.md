# xBotV3 Mini App

Este é o Mini App do xBotV3, uma aplicação web integrada ao Telegram para visualização de dados de criptomoedas e gerenciamento do bot de trading.

## Funcionalidades

- **Dashboard**: Visualização geral do portfólio e desempenho
- **Portfólio**: Detalhamento dos ativos em carteira
- **Mercado**: Lista de moedas disponíveis com preços atualizados
- **Gráficos**: Análise técnica e gráficos de preços por período
- **Alertas**: Configuração de alertas de preços

## Estrutura

- `index.html` - Página principal com menu de navegação
- `dashboard.html` - Visão geral do portfólio
- `portfolio.html` - Detalhamento dos ativos
- `market.html` - Lista de criptomoedas disponíveis
- `chart.html` - Gráficos detalhados de uma criptomoeda específica
- `css/` - Arquivos de estilo
- `js/` - Scripts de funcionalidade

## Tecnologias

- HTML5, CSS3, JavaScript
- Chart.js para gráficos
- Telegram Web App API para integração com o bot

## Integração

Este Mini App é integrado ao bot xBotV3 no Telegram, permitindo uma experiência de usuário aprimorada através da interface web dentro do aplicativo Telegram.
